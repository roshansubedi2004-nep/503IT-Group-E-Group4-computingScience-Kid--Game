# 503IT Group E - Group 4  
## Password Defender

## Project Overview

**Password Defender** is an educational cyber-safety game created for the 503IT Communication and Collaboration module. The aim of our project is to teach teenagers and university students about password safety through a simple interactive game.

The game helps users understand weak passwords, reused passwords, password theft, hacking risks, and the importance of creating strong and secure passwords.

## Project Aim

Our aim is to design and develop a simple educational cyber-safety game that teaches users how to create stronger passwords and avoid unsafe password habits.

The game should help users learn how to:

- Create strong passwords
- Avoid common password mistakes
- Understand password threats
- Avoid using personal information in passwords
- Learn through feedback, scores and rewards
